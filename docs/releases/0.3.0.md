# AoE4 Overlay 0.3.0 — beta para compartir

- Primer inicio guiado: build, detección, comparación de los cinco contadores y confirmación.
- Paquete de una apertura por civilización, con fuentes, atribución y criterios de avance.
- Ayuda con diagnóstico revisable y copiable, sin capturas ni datos personales.
- Consulta manual de versiones en GitHub; instalación y respaldo manuales.
- GPLv3 con código fuente correspondiente incluido junto al instalador.

## Descarga

Usá `AoE4 Overlay_0.3.0_x64-setup.exe` en Windows x64. El instalador funciona para el usuario
actual y puede descargar WebView2 si falta. No necesitás herramientas de desarrollo.
Leé `quick-start.md`. `starter-pack.json` solo contiene builds: lo podés importar sin cambiar ajustes.

## Actualización

Exportá un respaldo, cerrá con **Salir de la app** e instalá encima. Se conserva la biblioteca
y las configuraciones existentes; el asistente se puede abrir desde Inicio.

## Limitaciones conocidas

- Beta sin firma digital. Windows puede advertir al ejecutar el instalador.
- OCR requiere un idioma compatible instalado y HUD visible en ventana sin bordes.
- Construcciones, edad y otras acciones no verificables por contadores requieren AvPág.
- Revisar fuentes no equivale a validar estrategia en el parche actual o jugar los 25 builds.
- Compatibilidad real Steam/Xbox, 4K y múltiples DPI todavía necesita la beta: ver compatibility.md.
- Sin autorización oficial específica para competitivo. Orientado a práctica.
- No hay actualización automática ni telemetría. GitHub solo se consulta al buscar versiones.
