# AoE4 Overlay 0.3.0 — public beta

- Guided first launch covers build selection, detection, and confirmation of all five villager counts.
- One opening per civilization, with sources, attribution, and advancement criteria.
- Reviewable diagnostics in Help with a copy option. Diagnostics exclude screenshots and personal data.
- GitHub update checks on demand, with manual installation and backups.
- GPLv3 licensing with corresponding source code included alongside the installer.

## Download

Run `AoE4 Overlay_0.3.0_x64-setup.exe` on Windows x64. The installer runs for the current user and can download WebView2 if needed. You can use the installed app without development tools.

See the [quick-start guide](../quick-start.md). You can import `starter-pack.json` without changing your settings.

## Upgrading

Export a backup, exit the app, and run the installer over your existing installation. Your library and settings carry over. You can reopen the setup wizard from Home.

## Known limitations

- The beta installer is unsigned. Windows may show a warning when you run it.
- OCR requires a supported Windows OCR language and a visible HUD in borderless windowed mode.
- Buildings, age-ups, and other actions outside the villager counts require Page Down.
- Source review covers the published instructions. Full playthroughs and current-patch strategy validation remain pending.
- Live testing on Steam and Xbox, 4K, and mixed-DPI setups remains pending. See the [compatibility matrix](../compatibility.md).
- The beta is intended for practice. Competitive use lacks specific official authorization.
- Updates are manual, and the app collects no telemetry. It queries GitHub when you check for updates.
