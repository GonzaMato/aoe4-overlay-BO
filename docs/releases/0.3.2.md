# AoE4 Overlay 0.3.2 — civilization flags

- Civilization flags appear in the build library, civilization filter, build selectors, editor and overlay.
- Flags recognize English and Spanish civilization names, including variants, and work offline.
- Visual selectors support arrow keys, Home/End, typing a prefix, Enter, Escape and Tab.
- Custom civilizations keep their names and use a neutral fallback icon.

Flag assets: Age of Empires IV © Microsoft, via [AoE4 World Overlay](https://github.com/aoe4world/overlay). Attribution is included with the app. Existing builds and settings are preserved.
