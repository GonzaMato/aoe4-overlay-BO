# AoE4 Overlay 0.3.3

- Added optional civilization colors in Settings → Overlay. The active build's flag inspires the overlay's accent, border, subtle background tint, and two-color top stripe.
- Includes all 25 bundled civilizations, with English and Spanish name support. Updates automatically when the active build changes, in both full and compact views.
- Keeps resource colors and dark backgrounds readable. Unknown civilizations use your custom accent, which is also restored when the option is turned off.
- The preference is saved locally and included in full backups. Existing installations keep their current appearance until enabled.

Validation: 63 automated tests passed; Svelte checks reported no errors or warnings.
