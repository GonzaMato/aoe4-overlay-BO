# AoE4 Overlay 0.3.10 (beta)

- Manual calibration can now read your saved regions when the four resource icons are covered, provided the blue idle-villager button is visible and all five counters are readable.
- Windows OCR has an extra pass for thin adjacent digits. It now reads the wood count of 11 in our HUD capture at 110% and 150% scale.
- Calibration waits for three consecutive readings with the same distribution across all four resources and the same idle count before offering confirmation.
- Reopening AoE4 resets the practice step and clock. Switching windows with Alt+Tab preserves the session.
- Open **Settings → Match → Counter calibration** for an annotated HUD example. **Show selection example** highlights the relevant region while you draw it.
