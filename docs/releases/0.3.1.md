# AoE4 Overlay 0.3.1 — English and Spanish interface

- The app opens in English by default. Choose Spanish in **Settings** to switch the interface language.
- The English starter pack (`starter-pack.en.json`) contains 25 build orders, one per civilization, with source attribution and advancement criteria. The Spanish edition remains available as `starter-pack.json`.
- Your existing builds, settings, and practice history carry over when you update.

## Download and update

Download `AoE4 Overlay_0.3.1_x64-setup.exe` for Windows x64 from [GitHub Releases](https://github.com/GonzaMato/aoe4-overlay-BO/releases). The installer runs for the current user and can download WebView2 if needed.

To update, export a backup from **Settings → Backup**, choose **Exit app**, and run the new installer. See the [quick-start guide](https://github.com/GonzaMato/aoe4-overlay-BO/blob/v0.3.1/docs/quick-start.md) to set up your first practice match.

The beta installer is unsigned, so Windows may show a warning. Real-world Steam, Xbox, 4K, and mixed-DPI testing remains pending. The [compatibility matrix](https://github.com/GonzaMato/aoe4-overlay-BO/blob/v0.3.1/docs/compatibility.md) records the verification results.
