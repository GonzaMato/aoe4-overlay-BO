# AoE4 Overlay 0.3.9

- Uninstalling now closes the app first. Before, the uninstaller didn't notice it running in the tray: the app kept running and its program file stayed behind.
- If the app is open when you start the installer, the installer asks to close it before anything else. Before, choosing "Uninstall first" while the app was open failed with "Couldn't uninstall", because the installed version's uninstaller couldn't close it.
- The installer asks for its language every time, preselecting the app's current language. If you pick a different one, the app switches to it on the next launch, even if you already had it installed. Before, the installer asked only once and the app kept its saved language.
- When a version is already installed, the options say what they do: both install this version, one after uninstalling the current one first. Before, "Uninstall" and "Do not uninstall" both ended up installing the app. To remove the app, use **Windows Settings → Apps**.
- The uninstaller's "Delete app data" option now says that it deletes your builds, settings and practice history.
